# grub-theme-fit

أداة تجعل ثيم GRUB يناسب شاشتك.

أغلب ثيمات GRUB مرسومة لدقة واحدة (غالبًا 1920x1080) وتضع كل شيء بـ**البكسل**. على شاشة أخرى تخرج القائمة في مكان خاطئ أو ضيقة أو خارج الحافة. تعيد هذه الأداة كتابة تخطيط الثيم لدقة شاشتك:

- **`auto`** (تلقائي): تكتشف شاشتك بنفسها.
- **`manual`** (يدوي): تختار من قائمة بكل الدقات الشائعة، أو تكتب الدقة.

مكتوبة بـRust، بلا أي مكتبات خارجية، وملف تنفيذي صغير. النسخة الإنجليزية: [README.md](README.md)

## التثبيت

تحتاج Rust (على Arch: `sudo pacman -S rust`).

```sh
cargo install --git https://github.com/mryujruu/grub-theme-fit
```

## الاستخدام

```sh
grub-theme-fit auto                          # ثيم GRUB_THEME وشاشتك، معاينة فقط
grub-theme-fit auto  caelestia-nexus --write # تطبيق التغيير (يحتاج sudo لمجلد /boot)
grub-theme-fit manual                        # اختر الدقة من قائمة
grub-theme-fit manual mytheme --resolution 1366x768
grub-theme-fit resolutions --ratio 16:9      # الدقات المعروفة
grub-theme-fit status                        # هل عُدّل هذا الثيم وإلى أي دقة؟
grub-theme-fit restore                       # إرجاع الأصل
```

يمكن أن يكون `THEME` ملف `theme.txt` أو مجلد ثيم أو اسم ثيم موجود في `/boot/grub/themes`. وإن لم تذكره تُستخدم قيمة `GRUB_THEME` في `/etc/default/grub`.

بدون `--write` ترى معاينة فقط ولا يتغيّر شيء. والكتابة داخل `/boot` تحتاج صلاحية root، فتطبع الأداة لك أمر `sudo` الجاهز.

## الوضعان

| | `auto` | `manual` |
|---|---|---|
| مصدر الدقة | `GRUB_GFXMODE` في `/etc/default/grub` (وهي الدقة التي يستعملها GRUB فعلًا)، وإلا أول شاشة متصلة في `/sys/class/drm` | قائمة مرقّمة بالدقات المعروفة، أو `--resolution WxH` |
| متى تستعمله | حين تكون شاشتك هي ما يستعمله GRUB | حين يعمل GRUB بدقة غير دقة سطح المكتب، أو لتجهيز جهاز آخر، أو إذا فشل الاكتشاف |

الدقات المعروفة (`grub-theme-fit resolutions`): نسبة 4:3 من 640x480 إلى 2048x1536، ونسبة 5:4 (1280x1024 و2560x2048)، ونسبة 3:2، ونسبة 16:10 من 1280x800 إلى 3840x2400، ونسبة 16:9 من 1280x720 إلى 7680x4320، والعريضة جدًا 21:9 و32:9. وأي دقة أخرى تعمل مع `--resolution`.

## الخيارات

| الخيار | وظيفته |
|---|---|
| `--design WxH` | الدقة التي رُسم لها الثيم. تُخمَّن عادةً. |
| `--style exact` (الافتراضي) | مثل `20%-3`: نسبة مع بضع بكسلات، دقيقة لهذه الدقة. |
| `--style percent` | مثل `20%`: نسب صحيحة فقط، تصلح لأي دقة لكنها أقل دقة. |
| `--layout stretch` (الافتراضي) | كل محور يتغيّر وحده. |
| `--layout center` | يحافظ التخطيط على تناسبه ويُكبَّر بمعامل واحد ويُوسَّط. الأفضل حين تختلف نسبة الشاشة كثيرًا. |
| `--scale-items` | يغيّر أيضًا `item_height` و`item_padding` و`item_spacing` وأحجام الأيقونات. |
| `--crop-background` | يضبط `desktop-image-scale-method` على `crop` فتُقصّ الخلفية بدل أن تُمطّ. |
| `--write` | يطبّق التغيير. بدونه ترى معاينة فقط. |
| `-y` / `--yes` | يقبل تخمينًا ضعيفًا لدقة التصميم دون توقف. |

## كيف تعمل

يسمح GRUB بأن تكون قيم `left` و`top` و`width` و`height` بكسلات (`380`) أو نسبة (`20%`) أو الاثنين معًا (`50%-300`). والنسب تُحسب بالنسبة للعنصر الأب. تحوّل الأداة قيم البكسل، بالنسبة للدقة التي رُسم لها الثيم، إلى قيم تناسب شاشتك.

- **بلا فقد:** لا تُعاد كتابة إلا الأرقام التي تتغيّر. التعليقات والمسافات والألوان والخطوط وأسماء الصور تبقى كما هي.
- **العناصر المتداخلة** (`hbox` و`vbox` و`canvas`) تُحوَّل بالنسبة لأبيها. وإن لم يكن للحاوية عرض وارتفاع تُترك أبناؤها كما هي وتخبرك الأداة بذلك.
- **القيم النسبية أصلًا** (`20%`) تبقى. والثيم الذي كله نسب تقول الأداة عنه "لا شيء للتحويل".
- **آمنة عند التكرار:** أول `--write` يحفظ الأصل في `theme.txt.fit-orig` (والإعدادات في `theme.txt.fit-meta`). وكل تشغيل لاحق يبدأ من الأصل، فلا تتراكم التعديلات. و`restore` يعيد الأصل.
- **دقة التصميم تُخمَّن** من نسبة صورة الخلفية ومدى امتداد التخطيط. فإن كان التخمين ضعيفًا (مثلًا لا توجد صورة خلفية) تتوقف وتطلب `--design WxH` بدل أن تخمّن بصمت.
- لا تعدّل `/etc/default/grub` ولا تشغّل `grub-mkconfig`. فـGRUB يقرأ `theme.txt` عند الإقلاع.

## ما لا تستطيع فعله

- **الخطوط.** خطوط GRUB (`.pf2`) صور نقطية بحجم ثابت. على دقة مختلفة جدًا قد يبدو النص كبيرًا أو صغيرًا. تحذّرك الأداة، ويمكنك إنشاء خط بحجم جديد بـ`grub-mkfont -s <الحجم>`.
- **الصور.** الأيقونات وقطع الإطارات (`select_*.png`) تبقى بحجمها. و`--scale-items` يغيّر الأحجام في التخطيط لا الصور.
- **الشكل المختلف.** لا تستطيع النسب تحويل تصميم 16:9 إلى تصميم جيد لشاشة 5:4. ويساعد `--layout center` و`--crop-background`، وكذلك اختيار ثيم مصنوع لشكل شاشتك.
- **أحجام العناصر.** لا يقبل GRUB النسب في `item_height` وباقي إعدادات العناصر، فتبقى بالبكسل.

## الحالة

الإصدار 0.1.0. التحويل مغطّى بـ46 اختبارًا (وحدات وتشغيل كامل)، منها تخطيط حقيقي (Caelestia Nexus لشاشة 1280x1024). لم أُقلع بعد ثيمًا محوّلًا على أجهزة كثيرة، فأبلغ عن أي ثيم يخرج خطأ مع إرفاق ملف `theme.txt`.
